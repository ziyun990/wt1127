# Huang 公开参数下的固定工单机会维护排程实验

本仓库保存 2026 年 11 月 27 日的最新经济滚动修订版代码、输入、原生执行轨迹、结果和核验记录。两组共用 WOMBAT 物理执行层，分别采用 Huang/WOMBAT 基准调度和修订后的经济滚动排程。旧固定工单模型保留为对照。

**这是一项基于 Huang 公开参数构造的策略实验，不是原论文多年全场景的完整复现，也不是未修改 `wt0929_release` 的直接运行。**修订版保留原候选生成，重写经济目标和路线模式 MILP；移除了故障完工奖励与固定风险暴露奖励。

## 核验与限制

主、补充场景均已全部完工。核验包括工单编号、逐单工时、材料费、信息释放、派工船舶和序列最早启动时刻；有 768 张修订版工单的执行追踪。1361 条基准事件回放一致。原工作区 355 个原版文件未修改，其原始清单与验证记录保存在 `provenance/`；本仓库只收录运行所需的原模型源码快照，其清单另行列出。

预测路径采用近似。实际成本按 WOMBAT 已执行事件与状态结算；尚不能视为精确逐时计划或任意长度全局航线的完整验证。9 次日优化达到时间上限，部分没有有效有限最优界，不能将全部解称为已证明最优。

同机位零时长航段的原生日志有时记录无穷距离。两组结算仅对此类经核实的自环改为零距离，原始日志保留，见补充结果的 `self_distance_corrections.csv`。
